# 깊은 페이지 조회 — 닉네임 포함 랭킹 목록, Redis vs MySQL

- 일시: 2026-10-19 00:41
- 인원: 1,000,000명, 점수 0~999,999 균등 난수(seed 42)
- 시나리오: offset 위치부터 10명을 (user_id, 닉네임, 점수)로 조회. offset마다 30회 평균(워밍업 3회 제외)
- 스키마: `ranking(user_id PK, score, KEY(score, user_id))` + `users(user_id PK, nickname VARCHAR(32))`
- mysql-join: `ranking JOIN users … ORDER BY score DESC, user_id DESC LIMIT 10 OFFSET n`
- mysql-deferred: 지연 조인. `(SELECT user_id, score FROM ranking ORDER BY … LIMIT 10 OFFSET n)`을 users와 JOIN
- mysql-snapshot: 순위 테이블 `rnk BETWEEN n+1 AND n+10` + users JOIN
- redis: `ZREVRANGE` + 닉네임 해시 `HMGET` (2회 왕복)

> 적재 완료 (31.9s)

> 결과 일치 확인: offset 8곳에서 네 방식의 (user_id, 닉네임, 점수) 10명 비교 → 불일치 0건
